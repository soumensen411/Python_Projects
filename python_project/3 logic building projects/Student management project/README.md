# 🎓 Student Management System (CLI)

A simple **Command-Line Student Management System** built using Python.  
This application allows users to store, manage, and evaluate student marks with automatic grade calculation using JSON for persistent storage.

---

## 🚀 Features

- ➕ Add new students with marks  
- 📋 View all students  
- 🔍 View individual student result  
- 🎯 Automatic grade calculation  
- 💾 Persistent storage using JSON  
- 🛡 Input validation (marks must be numeric)  
- ⚡ Auto-save after adding students  

---

## 🧠 How It Works

- Student data is stored in a dictionary format
- Data is loaded from `student.json` at runtime  
- New students are added and saved instantly  
- Grades are calculated dynamically based on marks
