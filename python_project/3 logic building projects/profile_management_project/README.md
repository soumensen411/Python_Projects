# 📇 Profile Management System (CLI)

A simple and efficient Command-Line Profile Management System built using Python.  
This application allows users to manage contact profiles with full CRUD operations (Create, Read, Update, Delete) using a JSON file for persistent storage.

---

## 🚀 Features

- Add new profiles  
- Update existing profiles  
- Search profiles by name (case-insensitive)  
- Delete profiles  
- Persistent data storage using JSON  
- Input validation to prevent crashes  
- Auto-save after every operation  

---

---

## 🧠 How It Works

- The program loads data from `profile.json` at startup  
- All operations are performed in memory  
- Changes are automatically saved after every modification  
- Profiles are stored as a list of dictionaries
